# QPX agent bootstrap

Before the first command or repository/runtime inspection that performs actual
QPX work in a continuous session, read `QPX_CODEX_RULES.md` completely once.
Do not reread it for every prompt in that session unless the file changes.

Ordinary discussion, explanation, and planning require no compliance-file read
unless they mutate or operate QPX. For audits or rule disputes only, consult
`docs/governance/QPX_RULE_TRACEABILITY.md` and its referenced archive.

Directory-specific `AGENTS.md` files may add compatible local instructions.
